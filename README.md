# Retail Sales Analysis

## Project Overview

This project analyzes retail sales data to identify patterns in sales, profitability, discounts, regions, product categories, and customer segments.

## Tools Used

- Python
- Pandas
- NumPy
- Google Colab
- Tableau
- VS Code

## Data Analysis Process

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Business Insights

## Key Findings

- Technology generated the highest profit.
- The West region recorded the highest regional profit.
- Consumer customers generated the highest sales.
- Higher discount levels were associated with significant losses.

## Project Structure

- `01_data_cleaning.py` — Python data-cleaning pipeline
- `Retailsales.ipynb` — Exploratory data analysis notebook
- `retail_sales_clean (2).csv` — Cleaned dataset

## Conclusion

The project demonstrates how raw retail data can be transformed into useful business insights using Python-based data analysis and Tableau visualization.
